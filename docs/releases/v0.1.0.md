# RustOS v0.1.0 Release

**Release Date:** 2024-01-15  
**Codename:** Foundation  
**Kernel Version:** 0.1.0  
**License:** MIT/Apache-2.0

## Overview

RustOS v0.1.0 "Foundation" marks the first production-ready release of our Rust-based operating system kernel. This release provides a solid foundation for systems programming with memory safety, concurrency primitives, and essential OS functionality.

## Download

### Source Code
```bash
git clone https://github.com/rust-os/rustos.git
cd rustos
git checkout v0.1.0
```

## System Requirements

### Minimum
- **CPU:** x86_64 compatible processor (dual-core recommended)
- **RAM:** 256 MB
- **Storage:** 512 MB
- **Boot:** BIOS or UEFI

### Recommended
- **CPU:** x86_64 quad-core with VT-x/AMD-V
- **RAM:** 1 GB
- **Storage:** 2 GB SSD
- **Network:** Virtio or Intel e1000 compatible

## Installation

### From ISO (QEMU)
```bash
qemu-system-x86_64 \
  -cdrom rustos-v0.1.0-x86_64.iso \
  -drive file=rustos.img,format=raw \
  -m 1G \
  -smp 2 \
  -boot d
```

### From Source
```bash
# Prerequisites
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup default nightly
cargo install cargo-xbuild

# Build
git checkout v0.1.0
cargo xtask build --arch x86_64

# Run in QEMU
cargo xtask run --arch x86_64
```

### Network Boot (PXE)
```bash
# Extract kernel from ISO
mount -o loop rustos-v0.1.0-x86_64.iso /mnt
cp /mnt/boot/kernel.bin /tftpboot/

# PXE configuration
# DEFAULT rustos
# LABEL rustos
# KERNEL kernel.bin
# APPEND init=/bin/sh
```

## What's New

### Core Kernel
- ✅ Complete memory management with paging and frame allocation
- ✅ Multi-core SMP support with CPU hotplug
- ✅ Advanced synchronization primitives (ticket locks, RCU, RW locks)
- ✅ Robust error handling throughout kernel

### Filesystem
- ✅ Ext4 read-write support with journaling
- ✅ Journal replay for crash consistency
- ✅ Virtual filesystem (VFS) layer
- ✅ Basic POSIX file operations

### Networking
- ✅ TCP/IP stack with full state machine
- ✅ BSD socket API (socket, bind, connect, accept, send, recv)
- ✅ UDP and raw socket support
- ✅ Loopback and virtio-net drivers

### Security
- ✅ User namespaces for UID/GID isolation
- ✅ Linux capabilities system
- ✅ Process credential management
- ✅ Capability dropping for privilege separation

### Power Management
- ✅ ACPI sleep states (S1-S5)
- ✅ CPU idle states (C1-C4)
- ✅ CPU frequency scaling
- ✅ Thermal monitoring

### Drivers
- ✅ Virtio block/network/console
- ✅ Intel e1000e Ethernet
- ✅ AHCI SATA controller
- ✅ NVMe storage
- ✅ USB xHCI (basic)

## Known Issues

1. **GPU Display:** Wayland compositor path incomplete; basic framebuffer only
2. **USB:** Full device enumeration not implemented
3. **WiFi:** No wireless network support yet
4. **Audio:** Sound drivers not included

See [GitHub Issues](https://github.com/rust-os/rustos/issues) for full list.

## Changelog

### v0.1.0 (2024-01-15)

#### Added
- TCP state machine with RFC 793 compliance
- Socket syscalls (socket, bind, connect, accept, send, recv, shutdown)
- User namespace isolation with UID/GID mapping
- Full capability system with 41 capability types
- Ext4 journal replay for crash recovery
- Ticket locks and reader-writer locks
- RCU (Read-Copy-Update) pointers
- ACPI power management with S3/S4/S5 support
- CPU C-state idle management
- Code coverage integration in CI

#### Changed
- Replaced all unwrap() calls in drivers with proper error handling
- Improved ext4 write performance with block caching
- Enhanced TCP window management

#### Fixed
- Memory leak in process cleanup
- Race condition in scheduler
- Incorrect ACK handling in TCP established state

#### Removed
- Deprecated legacy boot protocol
- Unused ISA driver scaffolding
